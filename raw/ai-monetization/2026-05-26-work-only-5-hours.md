얼굴 없는 유튜브 채널 운영하는 사람들의 공통점.

월요일: "이번 주에 영상 3개 만들자"
금요일: 대본은 반쯤, 썸네일은 초안, 업로드 X

문제는 아이디어가 부족한 게 아닙니다.
콘텐츠 제작 과정 자체가 시간을 통째로 잡아먹는 것.

필요한 건 동기부여가 아니라 '시스템'.

클로드 코드로 기획→대본→음성→영상→업로드까지
하나의 파이프라인으로 묶는 24시간 자동화 팀 구축법.

▎0단계. 시작 전 반드시 지킬 3가지 원칙

① 직접 못 하는 건 자동화하지 마세요
좋은 대본·나쁜 대본 구분 못 하면 클로드 결과물의 오류도 못 잡습니다.

② 처음부터 90% 자동화는 금물
하루 1시간 아끼는 작은 단계부터. 복리 효과를 노리세요.

③ 내 이름 걸고 내보낼 수 있는가
도구가 훌륭해도 제작자 기준이 낮으면 망합니다.

▎1단계. 환경 설정 (클로드 + VS Code)

클로드 데스크톱 앱 다운로드
+ 마이크로소프트 VS Code 병행

이유: 클로드가 파일 생성하는 과정을 실시간 모니터링 가능.
앱 안에선 안 보이지만 IDE에선 다 보입니다.

폴더 구조 핵심:
- Context 폴더 (썸네일 예시·아바타·브랜드 가이드)
- Claude 폴더 (스킬·에이전트 정보)
- claw.md 파일 (전체 시스템 지침)

claw.md가 있으면 클로드가 폴더 맥락을 한 번에 파악합니다.
일관된 작업 = 자동화 성패의 핵심.

▎2단계. 스킬 + 에이전트로 제작팀 구성

스킬 = 클로드의 개별 능력치
에이전트 = 스킬을 조합해 임무 수행하는 주체

콘텐츠 전략·리서치 스킬
- 유튜브 60일 이내 급상승 '아웃라이어' 영상 탐색
- 인스타 릴스, X 트렌드까지 교차 분석
- 브랜드 보이스 맞춤 비디오 아이디어 5개를 대시보드로 제공

브랜드 보이스 가이드
클로드 마이크 기능으로 말로 설명:
"내 채널의 성격은 ○○, 말투는 ○○, 선호 컬러는 글래스모피즘"
→ 클로드가 브랜드 가이드 파일 자동 생성
→ 이후 모든 대본·썸네일이 이 가이드를 엄격히 따름

▎3단계. 휴먼 게이트(Human Gates) - 노션 통제실

100% 자동화는 위험.
유튜브 알고리즘이 양산형 콘텐츠를 식별해 제재합니다.

해법: 각 단계 사이에 '인간 승인 지점' 배치.

노션 칸반 보드 = 중앙 통제실

작동 방식:
카드를 다음 단계로 이동
→ 클로드 에이전트가 감지
→ 자동 실행 (예: 대본 작성 후 썸네일 제작)
→ 사용자는 초안 검토 후 '승인'만

▎4단계. 전체 파이프라인 + 도구 구성

기획 (트렌드 리서치)
→ VidIQ + 클로드 스킬
→ 휴먼 게이트: 아이디어 승인

관리 (콘텐츠 캘린더)
→ Notion 칸반

제작 (대본·썸네일)
→ 클로드 + Higgsfield
→ 브랜드 보이스 자동 적용

편집 (음성·립싱크)
→ 11 Labs + Dreamface
→ 휴먼 게이트: 대본 최종 검토

배포 (업로드·예약)
→ 클로드 에이전트 + Gmail
→ 휴먼 게이트: 최종 수동 발행

▎5단계. 루틴 스케줄링 + 비용

클로드 '루틴(Routines)' 기능으로 스케줄링.

예시 설정:
매주 월요일 오전 8시
→ 리서치 에이전트 자동 가동
→ 새 아이디어 탐색
→ 노션에 기록
→ 이메일 알림

비용 구조 (외주팀과 비교 시 압도적):
- 클로드 프로: 월 $17~20
- VidIQ / Higgsfield / 11 Labs: 사용량에 따라 추가
- VS Code / Notion: 무료

자동화의 본질

완벽한 도구를 찾는 게 아닙니다.
한 도구의 출력값 → 다음 도구의 입력값.
이 흐름을 유기적으로 설계하는 게 자동화입니다.

크리에이터는 더 이상 단순 반복 업무에 시간 쓰지 마세요.
콘텐츠의 '방향성'과 '전략'에만 집중하세요.

오늘 할 일:
브랜드 가이드 1개 + 하루 1시간 아끼는 스킬 1개.
여기서부터 시작입니다.
