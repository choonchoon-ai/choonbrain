천천히 읽어보세요


인스타에서 손으로 리드 찾고
일일이 이메일 보내고
답장 없으면 다시 보내고…
이걸 100% 자동화한 시스템이 등장했습니다.


리드 10,000명 확보 비용: 약 $1,000
전환율 1% × 객단가 $2,000 가정 시
→ 매출 $200,000 / 순수익 $199,000
리드 한 명당 약 130원.


클로드 코워크로 구축하는 '잠들지 않는 영업팀' 5단계.
▎1단계. 클로드 프로젝트 + 지침 세팅
일반 채팅창이 아닌 '프로젝트' 기능을 써야 합니다.
이유: 프로젝트 지침에 비즈니스 맥락을 미리 학습시킬 수 있기 때문.
지침에 넣어야 할 것:

본인 이름·발신 이메일
타겟 국가 / 타겟 오디언스
제공 서비스(Offer)
리드 자격 요건(Qualification rules)

매번 같은 내용을 묻지 않아도 AI가 스스로 판단합니다.
→ 프롬프트 간소화 + 크레딧 절약.
▎2단계. 데이터 추출 도구 연동
클로드는 인스타를 직접 스크래핑 못 합니다.
커넥터로 외부 도구 2개를 붙입니다.
Apify (아피파이)
→ 해시태그로 타겟 비즈니스 프로필 수집
(예: 헤어살롱 해시태그 → 수천 개 계정 정보)
Firecrawl (파이어크롤)
→ 프로필에 이메일 없으면 웹사이트 들어가서 실제 비즈니스 이메일 발굴
모든 도구 권한은 '항상 허용(Always allow)'으로 설정.
→ 사람 개입 없는 완전 자동 운영의 조건.
▎3단계. 아웃리치 스킬 장착
단순 발송이 아니라 응답률을 끌어올리는 스킬을 붙입니다.
이메일 응답 관리 스킬

인박스 모니터링
새 응답에만 답장
진행 중 스레드 중복 발송 방지

컨택폼 제출 스킬(Contact Form Submitter)

이메일 없는 사이트는 '문의하기' 페이지로 진입
폼 자동 작성·제출

이메일 비공개 잠재 고객까지 빠짐없이 공략.
▎4단계. 매일 자동으로 돌아가는 워크플로우
시스템이 매일 오전 8시(설정 시간)에 스스로:

새 리드 탐색
신규 발송 + 4일 이상 무응답 고객 후속 메일
모든 결과를 HTML 대시보드에 업데이트

초기엔 소량 리드로 정확도 테스트 → 성과 검증 후 확장.
▎5단계. 무한 확장 구조
검증 끝나면 해시태그 수·스크래핑 포스트 수를 늘리는 것만으로 무한 확장됩니다.
월 비용 구조:

클로드 유료 플랜: 약 $20
Apify: 무료 플랜 가능
Firecrawl: 무료 플랜 가능
클로드 코워크: 플랜 포함

기술 설정보다 중요한 건 '실행'.
