연 매출 3,400억 원의 캘린들리(Calendly).
이걸 단 15분 만에 클론할 수 있다면 믿으시겠어요?

프로토타입이 아니라
캘린더 연동 + 로그인까지 되는 '실제 작동 앱'.

코드 한 줄 안 쓰고 일상 언어만으로 만드는
'바이브 코딩(Vibe Coding)' 실전 가이드입니다.

▎왜 지금 앱을 만들어야 하나

SaaS는 1인 기업가에게 가장 매력적인 모델입니다.
한 번 만들어두면 매달 들어오는 반복 매출(Recurring Revenue).
아마존 프라임처럼 매번 설득할 필요 없는 안정적 현금흐름.

성공한 앱은 자산이 됩니다.
플립파(Flippa)·어콰이어(Acquire.com)에서 거액에 매각 가능.

틈새 시장 사례:
- TidyCal: 연 100만 달러+
- Book Like a Boss: 2024년 140만 달러

▎1단계. 테크 스택 분리: 클로드 디자인 + 코덱스

두 도구의 강점을 전략적으로 나눠 씁니다.

클로드 디자인 (Claude Design)
→ 프론트엔드 UI 설계 담당.
프롬프트 한 번에 세련된 디자인 + 실제 클릭·페이지 이동 가능한 구조 생성.

챗GPT 코덱스 (GPT 5.5)
→ 백엔드 기능 + 자동 테스트 담당.
'Browser Use' 스킬로 만든 앱을 스스로 테스트하고, DALL-E 내장으로 비주얼 자산까지 즉석 생성.

▎2단계. 실전 빌드 4단계

① 기능 기획
코덱스에 "캘린들리 같은 앱 만들 건데 핵심 기능 10개 제안해줘"
→ 계정 관리, 공개 예약 페이지, 캘린더 통합 등

② UI 디자인 생성
코덱스 이미지 생성으로 대시보드·예약 페이지 시안 5종 확보 → 1개 선택

③ 프론트엔드 제작
선택한 시안 스크린샷을 클로드 디자인에 업로드
→ 모든 버튼 작동 + 페이지 이동 가능한 HTML/CSS 자산 생성

④ 백엔드 결합
클로드 파일을 코덱스로 import → 실제 기능 입히기
브라우저 스킬로 예약 기능까지 직접 시연 검증

▎3단계. 고도화: API 연동 + 마케팅 영상

구글 캘린더 연동
구글 클라우드에서 클라이언트 ID 발급 → 코덱스에 "구글 로그인·캘린더 설치해줘"
복잡한 API 과정도 AI가 단계별로 가이드.

런칭 홍보 영상 자동 생성
코덱스의 리모션(Remotion) 플러그인 활용
→ AI가 앱 UI 캡처 + 버튼 애니메이션 추가
→ 마케팅용 영상 자산 즉시 확보

▎4단계. 로컬 → 실서비스 배포

로컬 앱을 전 세계가 쓰는 서비스로 전환:

- Supabase: 무료 DB 연동 (사용자 정보 저장)
- GitHub: 완성된 코드 저장
- Vercel: 개인 도메인으로 무료 호스팅

이 과정도 전부 코덱스에 "절차 알려줘"만 하면 끝.

전통 개발 vs 바이브 코딩

- 필요 역량: 프로그래밍 언어 → 일상 언어
- 소요 시간: 수개월~수년 → 15분~1시간
- 개발 비용: 수천만 원 인건비 → AI 구독료
- 수정·피드백: 코드 재배포 → 채팅으로 즉시 수정
