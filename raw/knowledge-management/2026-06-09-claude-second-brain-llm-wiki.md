영상 속 내용 정리했습니다. 천천히 읽어보세요

AI와 대화하며 얻은 통찰이 대화창 닫는 순간 다 사라진다는 것.
이게 일반 AI 채팅의 치명적 한계입니다.
테슬라 전 AI 책임자 안드레 카파시(Andrej Karpathy)가 이 문제를 해결하는 'LLM 위키'
패턴을 공개했지만 복잡한 기술 장벽 때문에 실제로 구현한 사람은 소수.
이제 복잡한 벡터 DB도, RAG도, 옵시디언도 필요 없습니다.
클로드 코드 안에서 단 하나의 프롬프트로 끝.
게다가 시간이 갈수록 스스로 진화합니다.
첫날보다 100일째에 훨씬 강력해지는 '자가 진화형' 구조.

## 왜 'LLM 위키'인가

안드레가 직접 운영 중인 시스템 규모:
- 100개+ 문서
- 40만 단어+
- 모두 마크다운(Markdown) 기반

핵심 철학: 지식을 복잡한 기술 레이어에 가두지 않습니다.
인간과 AI 모두 읽기 쉬운 마크다운 + 단순 폴더 구조. → 맥락의 연결성 극대화.

클로드 코드의 핵심 가치: 사용자가 수동으로 폴더·파일 정리할 필요 X.
설계된 프롬프트 한 줄 → 클로드가 스스로 안드레 지침대로 구조 생성.

## 1단계. 시스템의 5대 빌딩 블록

📁 Inputs (Raw 폴더)
모든 연구 자료, 웹 기사, 파일 덤핑장. 정리 안 되어 있어도 OK. 조직화는 AI 담당.

📁 Wiki (조직화 레이어)
AI가 Raw를 요약·연결해 검색 가능한 형태로 재구성.
- Index.md: 전체 지식의 지도
- Log.md: 변경 사항 기록

📁 Outputs
위키 기반으로 만들어진 최종 결과물. PDF, 슬라이드, 앱 코드 등.

📄 claw.md (운영 매뉴얼)
시스템의 '운영체제(OS)'. AI가 읽기·쓰기·유지관리하는 모든 규칙 포함.
AI가 스스로 이 파일을 업데이트하며 시스템 진화.

🔄 Dream Sequence (자가 진단)
주기적으로 실행돼서: 위키 내 모순 발견 / 중복 제거 / 새 입력 기반으로 최신화.

## 2단계. 실전 구축 + 운영 방법

초기 설정: 클로드 코드에서 프롬프트 실행 → 폴더 구조 자동 생성 → claw.md 자동 설정

데이터 주입 방법:
- 웹 링크 공유 또는 Raw 폴더에 파일 투입만
- 모바일에선 공유 기능으로 링크 보내고 "저장해줘" 한 줄
- → 클로드가 자동 Ingest + 위키 업데이트

지능형 인덱싱: 주입 데이터 분석 → Index.md에 자동 정리: 핵심 개념 / 주요 엔티티 / 출처.
Processed.md로 어떤 파일이 통합됐는지 추적 → 중복 작업 방지.

## 3단계. 자가 유지보수의 핵심: 드림 시퀀스

이 시스템이 다른 지식 관리 도구와 다른 결정적 이유.
안드레는 이걸 시스템의 '건강 검진'이라고 정의.

작동 방식:
- 매주 또는 매일 지정 시간에 자동 실행
- → Raw 폴더의 새 파일 확인 → 기존 위키와 통합 → 모순·낡은 정보 감시 → 새 연결 고리 자동 생성

수동 실행도 가능: "드림 시퀀스 실행해줘" → 즉시 전체 최신화
→ 지식 베이스가 단순 저장소가 아니라 스스로 학습하는 유기체처럼 작동.

## 4단계. 커스터마이징

무한 확장 가능한 구조. 운영 방식 변경 예시:
"새 파일 주입 시 자동 업데이트하지 말고 드림 시퀀스에서 한 번에 처리해줘" → 즉시 운영 방식 전환
주기 변경: 주간 → 일간 변경으로 최신성 강화 가능.
딥 리서치 통합: 특정 주제(예: AI 에이전트 산업 분석) 딥 리서치 지시 → 결과를 즉시 위키에 통합
→ 전문 지식 자산 빠르게 축적.

## 5대 구성요소 한눈에

- Raw 폴더 → 원시 데이터 덤핑장
- Wiki 폴더 → 연결·요약된 지식 (Index·Log·Processed)
- Outputs → 최종 산출물 (PDF·앱·슬라이드)
- claw.md → 시스템 운영 규칙
- Dream Sequence → 자가 진단·최신화 루틴

## 핵심 인사이트

AI와의 대화가 '일회성 소비'에서 '복리 자산'으로 전환되는 순간.
- 대부분의 사람: 대화 → 정보 휘발 → 매번 처음부터 설명
- 승자들: 대화 → 위키 자동 정리 → 시간이 갈수록 똑똑해지는 시스템

기술 장벽은 사라졌습니다. 이제 필요한 건 단 하나의 프롬프트.
오늘 클로드 코드 열고 시스템 가동하면 며칠 뒤 당신 비즈니스 맥락을 완벽히 이해하고
최적의 답변을 내놓는 동료가 생깁니다. 지식이 복리로 성장하는 첫걸음.
