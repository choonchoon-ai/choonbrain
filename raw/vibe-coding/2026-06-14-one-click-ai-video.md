유튜브만 보고 있는 사이 페이스북이 다시 떠올랐습니다.
종교 주제를 다루는 한 페이스북 페이지가

공개된 수익 인증을 통해

월 $26,000 (약 3,500만 원) 광고 수익 달성.
페이스북도 영상 게시물에 광고 수익 배분.

게다가 최근엔 AI 콘텐츠에 상대적으로 관대한 분위기.
핵심은 사람이 일일이 만드는 게 아닙니다.

클로드 코드 + 힉스필드로 제작 공정 90%를 자동화하는 것.
내 컴퓨터 안에 AI 콘텐츠 팀을 만드는 5단계 워크플로우.
▎1단계. 자동화 엔진 환경 세팅
웹 브라우저용 클로드로는 불가능합니다.

AI가 직접 파일을 생성하고 외부 도구와 통신할 권한이 필요해요.
필수 설치 3종:
① Node.js

자바스크립트 실행 환경.

공식 사이트에서 Windows MSI 다운로드 후 설치.
② 클로드 코드 데스크톱

브라우저 버전 X. 파일 시스템 접근 가능한 데스크톱 버전.

계정 연결까지 완료.
③ 힉스필드(Higgsfield) 스킬 이식

이미지·비디오 생성 담당.

터미널에서 전용 CLI 명령어 + 디바이스 인증

→ 채팅창 안에서 명령만으로 고퀄 시각 자료 생성 준비 완료.
▎2단계. 스크립트 기획 + 휴먼 터치
수익성 검증된 니치를 타겟팅하세요.
검증된 니치:

종교·성경
역사
미스터리
음모론

리서치 자동화

클로드에 한 줄 명령으로 10개 스크립트 추출

→ 5분이면 100개까지 확장 가능.
휴먼 에디트가 필수

AI 생성 글을 그대로 쓰면 위험합니다.

이건 참고 자료(Reference)일 뿐.
반드시 거쳐야 할 작업:

본인 스타일로 문장 다듬기
인간적 감성 추가
독창성 부여

이게 콘텐츠 품질 + 플랫폼 제재로부터 계정 보호 장치가 됩니다.
▎3단계. 비주얼 자동 생성
스크립트 준비됐으면 클로드 코드 모드로 전환.

단, 스크립트 던지고 바로 이미지 뽑으면 품질 저하.
3단계 정밀 작업:
① 장면별 프롬프트 사전 설계

클로드에 명령:

"이 스크립트의 각 장면에 맞는 상세한 이미지 프롬프트 10개 작성해줘"

→ 묘사 구체화 → 영상 전체 품질 비약적 상승
② 이미지 자동 생성 + 폴더 관리

힉스필드 스킬 + GPT Image Model 2 활용.

클로드가 지정 폴더에 고해상도 이미지를 차례로 저장.

콘텐츠 팀의 저장소 역할을 AI가 수행.
③ 4초 시네마틱 변환

정지 이미지로는 시청 지속시간 확보 불가.

명령:

"카메라가 천천히 안으로 들어가는 3D 느낌의 4초 비디오로 변환해줘"

→ 별도 비디오 폴더에 자동 분류 저장.
▎4단계. 보이스오버 전략
AI 음성에 대한 피로도를 고려해야 합니다.
추천 방식:

직접 녹음 (가장 강력)
11 Labs로 본인 목소리 클로닝 (대안)

이유:

실제 인간 톤이 시청 몰입도 ↑

플랫폼 알고리즘 친화적

▎5단계. 편집 + 렌더링
무료 편집 SW: 다빈치 리졸브(DaVinci Resolve)
자동화의 마침표

향후 다빈치 리졸브를 클로드 코드와 연결하면

AI가 직접 타임라인 배치 + 렌더링까지 수행 가능.

→ 콘텐츠 제작 풀파이프라인 자동화 완성.
━━━━━━━━━━━━━━
전통 vs 클로드 코드 자동화

소재 리서치: 수 시간 검색 → 프롬프트 1회로 10~100개 추출
시각 자료: 스톡 구매·직접 촬영 → AI 자동 생성
일관성 관리: 수작업 보정 → 장면별 프롬프트 사전 설계
파일 관리: 수동 분류 → AI가 자동 정리
영상 1개 시간: 반나절+ → 시스템 구축 후 10~20분

━━━━━━━━━━━━━━
핵심 인사이트
페이스북 무인 페이지 수익화는

AI에게 모든 걸 맡기는 게 아닙니다.
클로드 코드를 유능한 연구원 + 디자이너로 고용해서

제작 시간을 90% 단축하는 전략입니다.
승부의 핵심 2가지:

① 플랫폼이 선호하는 니치 선점

② 자동화 도구로 품질 높은 콘텐츠를 꾸준히 생산
기술 장벽은 이미 사라졌습니다.

실행하는 사람만이 새 수익 기회를 가져갑니다.
오늘 할 일:

클로드 코드 설치

→ 첫 스크립트 프롬프트 입력
여기서부터 시작입니다.
