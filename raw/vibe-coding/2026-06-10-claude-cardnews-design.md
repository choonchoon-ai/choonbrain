━━━━━━━━━━━━━━
AI로 만든 카드뉴스가 다 비슷비슷한 이유.

"멋진 카드뉴스 만들어줘" 한 줄로 끝내기 때문입니다.
이건 AI의 잠재력 절반도 못 쓰는 방식.

진짜 차별화는
AI에게 '나만의 디자인 언어'를 학습시키고
이걸 반복 가능한 시스템으로 박아두는 것에서 시작됩니다.

전 애플·닛산 아트 디렉터 출신 던컨 로고프(Duncan Rogoff)가
클로드 코드로 2~3분 만에 전문가 수준 카드뉴스 자동 생성하는 워크플로우.

디자인 감각 없는 초보도 바이럴 콘텐츠 제작자로 바뀌는 3단계.

▎1단계. 디자인 MD 파일로 '나만의 스타일' 박제

AI 결과물이 뻔해지는 이유는 가이드라인이 없어서.

작업 순서:
① 핀터레스트 등에서 원하는 스타일 레퍼런스 캡처
② 클로드에 명령:
"이 이미지를 HTML 디자인 시스템 + 디자인 MD(Design MD) 파일로 변환해줘"

디자인 MD 파일이란?
AI가 이해하는 언어로 정리된 규칙 문서.
- 색상 코드
- 서체
- 간격
- 레이아웃 룰

확장성의 핵심
이 파일 하나가:
- 카드뉴스
- 랜딩 페이지
- 뉴스레터
- 모든 시각 자산
에 동일하게 적용되어 브랜드 일관성 자동 유지.

▎2단계. 힉스필드 MCP 연결로 이미지 엔진 장착

디자인 규칙 정했으면 이제 실제 이미지를 만들 엔진.
클로드 코드의 MCP 기능으로 'Higgsfield'를 직접 연결.

연결 방법:
클로드 설정 - Connectors - Higgsfield 추가 + 로그인
- 끝.

이제 가능한 것:
사용자가 복잡한 이미지 프롬프트 쓸 필요 X.

명령 한 줄로 충분:
"디자인 시스템에 기반해 AI와 로봇공학에 관한 이미지를 생성해줘"

→ 클로드가 앞서 만든 디자인 MD 참고
→ 영화 같은 고품질 이미지 자동 생성
→ 브랜드 톤 100% 유지

▎3단계. '카드뉴스 제작 스킬' 등록

콘텐츠의 시각적 품질만큼 중요한 게 '구조'.
던컨이 검증한 바이럴 카드뉴스 구조를 '스킬'로 등록.

바이럴 카드뉴스 5단 황금 구조

① 커버 (Hook)
시선 잡는 강력한 후크 문구

② 문제 제기 (Pain)
타겟이 겪는 고통·문제를 직접 언급

③ 단계별 해결책 (Steps)
구체적 방법 Step 1, 2, 3 나열

④ 결과 공유 (Result)
해결책 적용 후 변화 제시

⑤ 행동 촉구 (CTA)
댓글·링크 클릭 등 명확한 다음 행동

스킬 등록의 위력
이후에는 주제 키워드 한 줄만 입력
→ 클로드가 자동 생성:
- 슬라이드별 텍스트
- 슬라이드별 이미지
- 인스타 캡션
- 링크드인 게시물

한 번에 모든 플랫폼 자산 완성.

━━━━━━━━━━━━━━

전통 방식 vs 클로드 시스템 방식

- 디자인 기획: 매번 레퍼런스 검색 → 디자인 MD로 스타일 고정
- 이미지: 유료 스톡·직접 촬영 → Higgsfield MCP 즉시 생성
- 구조: 기획자 역량 따라 기복 → 검증된 스킬 자동 적용
- 캡션: 슬라이드별 별도 작성 → 인스타·링크드인 동시 생성
- 소요 시간: 2~3시간+ → 2~3분

━━━━━━━━━━━━━━

핵심 인사이트

AI 시대 콘텐츠 제작의 본질이 바뀌었습니다.

❌ "얼마나 열심히 만드느냐"
⭕ "얼마나 정교한 시스템을 구축하느냐"

디자인 시스템 + 스킬 등록이 끝나면
사용자는 백지 앞에서 고민할 필요가 없습니다.
오직 "어떤 가치 있는 주제를 다룰 것인가"에만 집중하게 됩니다.

오늘 할 일:
클로드 데스크톱 앱 열기
→ 평소 마음에 들었던 디자인 레퍼런스 1개 업로드
→ 디자인 MD 파일 만들기

여기서부터 시작합니다.
