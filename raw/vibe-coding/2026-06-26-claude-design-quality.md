Claude Design 업데이트 4가지. 저장해두고 그대로 따라하세요

━━━━━━━━━━━━━━
▎1단계. 직접 편집 UI
이전: 모든 수정을 프롬프트로만 → 토큰 폭발
이제: 캔버스 요소 직접 클릭·편집.
텍스트·폰트·크기 즉시 변경, Figma 같은 레이어 뷰.
사소한 조정에 토큰 안 써도 됩니다.

▎2단계. 슬라이드 + PPTX 내보내기
주제만 던지면 디자인 시스템 기반 슬라이드 자동 구성.
전체화면 발표 모드 + 보조 모니터 발표자 노트.
Share → .pptx 가능, Canva·Gamma·Lovable·Vercel·Wix까지 연결.

▎3단계. Claude Code와 사용량 통합
이게 진짜 큰 변화.
Chat·Cowork·Code·Design 사용량 하나로 통합 → 오류율도 급감.
/design-sync로 코드 디자인 시스템을 Design으로 가져오기.
디자인 완성 → 클릭 한 번에 Claude Code로 전송 → 실제 작동 서비스화.

▎4단계. Markup + 외부 도구 확장
화면에 직접 그리거나 코멘트로 수정 지시.
"슬라이드에서 대시(—) 자제" 같은 상세 피드백 학습.
Higgsfield 연결하면 디자인 중 영상·이미지 즉석 생성.

━━━━━━━━━━━━━━
디자인·코딩·문서를 한 앱에서 끝내는 'Everything App' 방향.
컨텍스트 스위칭 비용을 0으로 만드는 게 목표입니다.
