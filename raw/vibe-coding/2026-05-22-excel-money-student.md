━━━━━━━━━━━━━━
구글 드라이브에 잠들어 있는 엑셀 시트.

그대로 팔면? 1~2달러 (레드오션 진입)
미니 웹 앱으로 바꾸면? $17~$97 (블루오션)

같은 데이터, 같은 로직.
포장만 바꿨을 뿐인데 가치가 50배 뜁니다.

이유는 간단해요.
사람들은 스프레드시트를 '숙제'처럼 느끼지만
버튼·필터·대시보드는 '결과'와 '속도'를 줍니다.

1시간 만에 만드는 미니 웹 앱 비즈니스.

▎1단계. 왜 미니 웹 앱인가

스프레드시트 vs 미니 웹 앱

- 경험: 정적인 그리드 → 인터랙티브 대시보드
- 가격: $1~5 (레드오션) → $17~97 (블루오션)
- 기능: 수동 계산 → 자동 워크플로우
- 인식: 누구나 만드는 템플릿 → 개발자가 만든 도구

고객은 정보에 돈 쓰지 않습니다.
'마찰 없이 결과 얻는 경험'에 돈 씁니다.

▎2단계. 도구 조합: 클로드 + 러버블

각자의 역할이 다릅니다.

클로드 (Claude) = 두뇌 / 기획자
러버블 (Lovable) = 손 / 빌더

왜 클로드 코드가 아니라 러버블인가?

초보가 클로드 코드로 직접 만들면
→ 로그인·DB·호스팅에서 막힘
→ 토큰 소모 폭발

러버블은 인증·DB 연결·실배포(Real URL)를 자동 처리.
초보에겐 압도적으로 유리합니다.

토큰 절약 워크플로우:
기획·브레인스토밍 = 일반 클로드 채팅
실제 구현 = 러버블

명확한 설계도 먼저, 빌드는 나중.

▎3단계. 실패 없는 기획 2가지 프롬프트

"건강 관리 앱 만들어줘" → 망함
명확한 맥락(Context)이 핵심입니다.

프롬프트 ①. 시스템 분석
"이 파일을 단순 데이터가 아닌 '제품 시스템'으로 분석해줘.
데이터가 어떻게 연결되는지,
사용자에게 주는 최종 결과는 뭔지 파악해서
제품 기획서(Product Brief)를 작성해줘."

프롬프트 ②. 아키텍처 결정
"코드를 쓰기 전에 내가 결정해야 할 사항이 뭐야?"

데이터 저장 방식, 공유 기능, 대시보드 항목 등
8~10개 질문에 90초만 답하면
나중에 앱 망가지는 걸 방지합니다.

▎4단계. 7단계 레이어링 구축법

한 번에 모든 기능 요청 ❌
층을 쌓듯이 단계별로 명령 ⭕

① 기반 (DB 구조, 로그인, 기본 틀)
② 온보딩 (첫 진입·정보 설정)
③ 핵심 기능 (데이터 입력 폼 등 메인)
④ 대시보드 (차트·숫자 시각화)
⑤ 보고서·내보내기 (PDF·CSV 추출)
⑥ 설정 (계정·프로필 관리)
⑦ 최종 마감 (모바일·로딩·디자인 미세조정)

이 순서를 지키면 논리적 오류가 거의 없습니다.

▎5단계. 일괄 디버깅 + 배포

완성 후엔 신규 사용자로 직접 가입해서
온보딩부터 출력까지 전 과정 테스트.

핵심 노하우: 일괄 수정(Batching Bugs)

버그를 하나씩 고치면 다른 데가 망가집니다.
모든 오류를 모아 한 번에 설명하고 이렇게 지시하세요:

"내가 나열한 것만 수정하고 다른 것은 건드리지 마.
(Fix only what I listed. Do not modify anything else.)"

이게 'AI 부작용'을 막는 마법의 문장.

배포는 러버블 클릭 한 번.
실제 작동하는 URL + DB 즉시 발급 → 바로 판매 가능.

핵심 요약

구글 드라이브에 이미 보물지도가 있습니다.
- 직접 쓰던 체크리스트
- 비즈니스 계산기
