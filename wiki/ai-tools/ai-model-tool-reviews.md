## Overview

AIMAX_PD 채널이 2026년 6~7월에 올린 AI 도구 리뷰 쇼츠 5편을 종합했다. 원본은 "미쳤음", "비밀병기" 류의 홍보성 쇼츠라 과장이 많으므로, 여기서는 검증 가능한 기능·워크플로우만 추린다. 다섯 편을 관통하는 공통 흐름은 뚜렷하다: (1) AI가 단순 질의응답 도구에서 **스킬·메모리·에이전트를 갖춘 업무 시스템**으로 이동하고 있고, (2) 유료 SaaS 구독을 **로컬·오픈소스로 대체**하려는 압력이 커지고 있으며, (3) NotebookLM·ChatGPT·Claude Fable 같은 주요 제품이 모두 **컨텍스트 축적 + 자동화 반복**이라는 같은 방향으로 수렴하고 있다는 점이다. 개별 수치 주장(예: "6배 성능", "토큰 99% 절감")은 벤더/영상 주장이므로 그대로 믿기보다 방향성으로 읽는 게 안전하다.

## 관통 주제: "질문창"에서 "업무 시스템"으로

세 가지 구성요소가 반복 등장하며, 사실상 이번 세대 AI 제품의 공통 골격이다.

- **스킬(Skills)**: 반복 업무를 포터블한 워크플로우로 패키징. 한 번 가르치면 매번 지시할 필요 없이 재사용되고, 브랜드 가이드·문체·톤까지 학습시킬 수 있다. ChatGPT는 시스템/계정/프로젝트 수준으로 스킬을 관리하고, Claude Fable은 시청자 반응 같은 피드백 데이터로 스킬을 스스로 갱신한다고 영상은 주장한다.
- **메모리·컨텍스트**: 모델이 아무리 똑똑해도 비즈니스 맥락이 없으면 일반론만 낸다. 로컬 폴더에 SOP·성공/실패 사례를 문서화하고 `memory.md`를 두면 대화 중 중요한 맥락을 자동 축적한다. 노하우가 모델 교체와 무관하게 사용자에게 남는다는 점이 핵심 가치다.
- **에이전트·자동화**: 스케줄 태스크(반복 수집·모니터링), 브라우저 제어(경쟁사 분석), 폼 작성·리서치 대행 등 실제 실행까지 위임한다.

## 구글 NotebookLM — 페이스리스 콘텐츠 파이프라인

"클로드보다 낫다"는 제목은 낚시에 가깝고, 실제 내용은 NotebookLM을 무료 콘텐츠 제작 인프라로 쓰는 5단계 워크플로우다.

1. 소스 박스에 니치 리서치 자료(Reddit·VidIQ 등)를 넣어 유망 주제 발굴.
2. 후보 니치를 실제 유튜브에서 검색해 수요를 검증(영상 기준은 "최근 4주 게시 + 20만 조회").
3. 성공 영상 URL을 넣어 요약이 아닌 전체 대본을 추출한 뒤, 주제는 유지하되 각도·구조만 재구성.
4. 스튜디오 패널의 비디오/오디오 오버뷰로 이미지+음성+편집을 자동 생성.
5. 이를 지역 업체 대상 영상 대행 서비스로 상품화.

핵심 통찰은 "값비싼 도구 보유가 아니라 무료 인프라를 얼마나 빨리 실행하느냐가 우위"라는 것. 다만 3단계의 타 채널 대본 이식은 저작권·표절 리스크가 있어 각도·구조 재구성 수준을 지키는 게 중요하다.

## Claude Fable 5 — 1인 기업 운영체제

Fable 5를 "1인 기업 OS"로 쓰는 4가지 축을 소개한다. 성능 주장(자기교정 벤치마크에서 이전 세대 대비 약 6배)은 영상 주장이니 방향성으로만 참고한다.

- **루프(Loops)**: 목표만 주면 스스로 반복·검토·개선. 매일 아침 시장 브리핑, 30분마다 이메일 스캔+플래그, 광고 소재 반복 최적화 등. 자기비판이 아니라 **목표 + 루브릭(성공 기준) + 검증자 서브에이전트**로 환경 피드백 기반 자기교정을 하는 구조가 요점이다.
- **스킬(Skills)**: 루프가 "반복"이라면 스킬은 "어떻게 잘할 것인가". 피드백 데이터로 스킬 자체가 갱신되고, 노하우는 사용자가 소유·이식하므로 모델이 바뀌어도 유지된다.
- **비전(Vision)**: 스크린샷 기반 UX 개선안 도출, 지저분한 PDF·손글씨 차트의 구조화된 표 변환, 디자인 시안 비평 등.
- **컨텍스트 시스템**: 로컬 폴더 + `memory.md` + Obsidian 연동으로 시각적 지식 네트워크를 구축.

주의: Fable 5는 사용량 제한이 있어 전략적으로 써야 한다고 영상도 명시한다.

## ChatGPT 5.6 — 업무 자동화 플랫폼

두 편(기능 개괄 10가지 + 마케팅 자동화 4단계)이 사실상 같은 메시지를 준다: ChatGPT는 이제 질문창이 아니라 브랜드를 기억하고 업무 도구와 연결되며 실무를 처리하는 시스템이라는 것.

- **스킬 + 커넥터**: 브랜드 가이드 학습(스킬), Gmail·Drive·Slack·Notion·Calendar·Canva·Figma 연동(커넥터)으로 통합 검색·자동화.
- **엔드투엔드 예시**: Notion 콘텐츠 캘린더에서 일정 추출 → 소셜용 이미지 자동 생성 → 구글 드라이브 지정 폴더 업로드.
- **실무 기능**: 음성 회의 실시간 전사+업무 분배, 메모리 관리, 라이브 프로젝트(연결 파일 자동 갱신), 엑셀·CSV의 인터랙티브 대시보드 변환, 모델·Thinking 강도 조절, 스케줄 태스크, 제품 사진 기반 광고 이미지, 에이전트 모드(브라우저 제어 경쟁 분석 등).
- **템플릿 크리에이터**: 기존 문서를 재사용 가능한 스킬로 변환해 개인·팀의 업무 표준을 통일.

## 오픈소스로 유료 SaaS 대체하기

"돈 내지 마세요" 편은 유료 구독을 로컬·오픈소스로 옮기는 5가지 도구를 소개한다. AI가 클라우드에서 로컬로 내려오는 흐름을 보여준다.

- **Open Montage**: 자연어 설명으로 리서치·스크립트·편집·렌더링. 생성 이미지 대신 실제 스톡 푸티지 사용, 클라우드 API 키 없이 로컬 구동.
- **Codebase Memory MCP**: Memory + LSP 결합으로 대규모 코드베이스 이해 토큰을 크게 절감(영상 주장 최대 99%). 함수 호출·변경 영향까지 추적.
- **Fluid Voice / Voice Box**: 각각 Whisper Flow·Super Whisper, 11 Labs 대체(맥 로컬). 실시간 교정, 30초 샘플 음성 복제.
- **Google TimesFM**: 매출·트래픽 시퀀스를 넣으면 추가 훈련 없이 다음 값을 예측(트렌드·계절성 반영). 시계열 파운데이션 모델.
- **Zapier MCP**: Gmail·Notion 등 앱을 AI 에이전트에 5분 만에 연결(구글 클라우드 설정 없이).

## 실전 팁·유의점

- 공통 실전 팁: 먼저 **컨텍스트/메모리를 문서로 축적**하고, **반복 업무를 스킬로 패키징**한 뒤, **에이전트/루프로 자동화**하는 순서가 반복 등장하는 정석이다.
- 벤더/영상의 수치 주장("6배", "99% 절감", "20만 조회 시그널")은 검증 없이 인용하지 말 것. 방향성 참고용.
- 무료·로컬 지향은 매력적이지만 사용량 제한(Fable), 로컬 하드웨어 요구(음성·영상 도구), 타 채널 대본 이식의 저작권 리스크 등 트레이드오프가 있다.
- 채널 자체가 커뮤니티 유입("댓글에 aimax")을 노린 홍보 채널이라는 점을 감안해 정보를 걸러 읽는다.
